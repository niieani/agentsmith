agentsmith turns reusable, Git-backed source material into the native context files that coding agents already understand. Define templates, packs, and skills once; select them for a machine or repository; then let `asmith` generate `AGENTS.md`, `CLAUDE.md`, and native skill directories.

Install the `asmith` command from npm with Node 24 or newer, through Homebrew on Apple Silicon macOS, or as a standalone binary from GitHub Releases.

## Why agentsmith?

- Keep shared instructions consistent across long-running machines.
- Adapt the same guidance to Codex and Claude Code.
- Compose project context for repositories and monorepo subtrees.
- Generate self-contained skills without runtime include chains.
- Review every change and protect hand-edited output.

## Two workflows

### Global context

A machine profile selects reusable packs and a template. `asmith global sync` fast-forwards the source repository and regenerates global instructions and skills.

### Project context

A checked-in project config declares repository and subtree scopes. `asmith project generate` renders local instruction layers and skills without pulling anything.
